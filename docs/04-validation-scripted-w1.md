## Defects found and fixed

1. **The ledger path collided with the dispatch scope check.** `hydra-pod-dispatch` treats only `_receipts/` and `_tickets/STATE.md` as manager records, so `_tickets/ledger.jsonl` made `build` and `accept` abort.
   - Fix: the ledger moved to `_receipts/ledger.jsonl`. An old ledger is moved automatically on first use.
   - Because `_receipts/` is exempt from the worker scope check, the ledger now carries a **hash chain** (`prev`). An edited, removed or reordered line is refused on read. Tests: `LedgerIntegrityTest`.
2. **No way to record a correction of the manager's own ticket.** The only moves out of `TESTING` were REWORK, ESCALATE and ABORT, and all of them blame the worker.
   - Fix: a new event `hydra/task-amended` (before, after, reason; the state is unchanged) and the command `wf amend`.
   - The skill now says: amend only a wrong ticket, never to make a real defect pass. Test: `AmendTest`.
3. (Minor) `hydra-pod-dispatch close` does not commit the ledger or the report. The skill now tells the manager to commit them.
